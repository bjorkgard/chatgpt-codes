# Getting Started

## What This Material Does

The source material shows how short code words can work as visual instructions. A code word can guide camera angle, presentation, diagram type, material, illustration, world, lighting, or educational format.

## Three Levels of Use

- Simple: write only the code word after uploading an image.
- Directed: combine the code word with a concrete goal and format.
- Advanced: combine two to four compatible code words and add constraints.

## Good Combinations

- Product ad: `/packshot + /rimlight + /storyad`
- Technical explanation: `/cutaway + /labels + /blueprint`
- Education: `/whiteboard + /keytakeaways + /diagram`
- Style test: `/watercolor + /goldenhour`
- Comparison: `/beforeafter + /featurematrix`

## Risks to Avoid

- Too many code words at once often produce cluttered images.
- Code words that pull in different directions can compete, for example `/minimal` and `/crunch explosion`.
- If identity, product shape, or colors must be preserved, say so explicitly.
- Text in generated images can be wrong; ask for short labels instead and always check the result.
