# Marshmallow Object

![Marshmallow Object example](../../../examples/prompts/surreal-still-life/076-surreal-still-life-marshmallow-object.png)

## Prompt

```text
Create an ultra-realistic sculptural version of [INSERT OBJECT] made entirely from soft white marshmallow.
Preserve the object’s recognizable silhouette, proportions, structure, defining features, and key visual details so it
remains immediately identifiable, while transforming every visible component into pillowy confectionery.

Form the object from bright creamy-white marshmallow with a soft, airy, slightly matte surface. Give it realistic
squishiness through gently rounded edges, subtle bulging, delicate compression where components meet, tiny dents,
faint wrinkles, and slight irregularities in thickness. Add a fine dusting of powder across the surface, collecting
naturally within seams, creases, and recessed details.

Include one small torn or stretched area revealing the fluffy, porous interior, with delicate wispy strands and an
uneven pillowy texture. Keep intricate features carefully sculpted from marshmallow rather than simplifying them.

Present the sculpture against a seamless bold pastel or saturated colored background, such as sky blue, cherry red,
sunny yellow, lavender, or vivid pink, creating strong contrast with the white marshmallow.

Use crisp directional studio lighting, soft dimensional shadows, gentle highlights, shallow depth of field, and
exceptional macro detail.

The final image should feel soft, whimsical, tactile, edible, surreal, photographic, and meticulously crafted. No
typography, logos, labels, packaging, branding, or additional decorative objects.
```
