# Chrome Object

![Chrome Object example](../../../examples/prompts/surreal-still-life/070-surreal-still-life-chrome-object.png)

## Prompt

```text
Create an ultra-realistic sculptural chrome version of [INSERT OBJECT]. Preserve the object’s recognizable
silhouette, proportions, structure, defining features, and key visual details so it remains immediately identifiable, while
transforming every visible component into seamless, mirror-polished liquid metal.

Craft the entire object from highly reflective silver chrome with an immaculate metallic surface, fluid contours, smooth
transitions, and a luxurious molten quality. Maintain crisp structural details while subtly rounding select edges to
create the impression of metal that has been poured, sculpted, and polished into shape.

Create realistic mirror reflections across every curved surface, with elongated highlights, distorted environmental
reflections, deep metallic shadows, bright specular streaks, and subtle tonal gradients. Allow small areas to appear
almost liquid, with gentle bulges, flowing transitions, and occasional suspended metallic drips while keeping the
original object clearly recognizable.

Present the sculpture as a futuristic luxury editorial still life against a seamless bold colored background, such as
cobalt blue, vivid pink, saturated red, electric purple, or bright orange.

Use dramatic directional studio lighting, crisp rim lighting, controlled reflections, luminous highlights, and a clean
grounding shadow.

The final image should feel sleek, futuristic, surreal, expensive, sculptural, photographic, and flawlessly polished. No
typography, logos, labels, branding, or additional decorative objects.
```

## Usage Notes

Replace [INSERT OBJECT] with a concrete object that has a recognizable silhouette. The examples use a vintage instant camera as the sample object.

The example image shown for this file uses made-up input details so the prompt can be previewed without a real upload.
