# Chocolate Object

![Chocolate Object example](../../../examples/prompts/surreal-still-life/069-surreal-still-life-chocolate-object.png)

## Prompt

```text
Create an ultra-realistic molded chocolate version of [INSERT OBJECT]. Preserve the object’s recognizable
silhouette, proportions, structure, defining features, and key visual details so it is immediately identifiable, while
transforming every visible component into luxurious solid chocolate.

Craft the object primarily from rich dark and milk chocolate with smooth molded surfaces, subtle tonal variations,
delicate imperfections, and an elegant satin sheen. Recreate seams, edges, textures, buttons, laces, hardware, or
other defining details as precisely molded chocolate elements.

Add one beautifully broken or snapped section along a natural outer edge, revealing a realistic solid chocolate
interior. Make the fracture irregular and crisp, with thin shards, tiny flakes, rough broken edges, and several scattered
chocolate fragments resting naturally nearby. Include subtle fingerprints, faint molding marks, fine chocolate dust, and
slight softening along select edges for realism.

Present the object as a sophisticated luxury editorial still life against a seamless warm cream, pale blush, or muted
pastel background.

Use refined directional studio lighting, rich dimensional shadows, crisp highlights, shallow depth of field, and
exceptional macro texture detail.

The final image should feel indulgent, modern, sculptural, photographic, luxurious, and surprisingly realistic. No
typography, logos, labels, wrappers, branding, or additional decorative objects.
```

## Usage Notes

Replace [INSERT OBJECT] with a concrete object that has a recognizable silhouette. The examples use a vintage instant camera as the sample object.

The example image shown for this file uses made-up input details so the prompt can be previewed without a real upload.
