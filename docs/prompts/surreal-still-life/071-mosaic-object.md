# Mosaic Object

![Mosaic Object example](../../../examples/prompts/surreal-still-life/071-surreal-still-life-mosaic-object.png)

## Prompt

```text
Create an ultra-realistic mosaic sculpture in the form of [INSERT OBJECT]. Preserve the object’s recognizable
silhouette, proportions, structure, defining features, and key visual details so it is immediately identifiable, while
transforming every visible surface into an intricate composition of thousands of tiny ceramic and glass tiles.

Cover the object with individually placed tesserae in varied shapes and sizes, including tiny squares, irregular
fragments, curved pieces, and delicate geometric sections. Use a sophisticated mixture of jewel tones, saturated
colors, pearlescent accents, translucent glass, glossy ceramic, and occasional mirrored pieces. Arrange the colors in
flowing patterns that naturally follow the object’s contours, seams, edges, and individual components.

Include realistic narrow grout lines, slight tile-height variations, tiny chips, imperfect edges, handcrafted irregularities,
glossy reflections, and subtle differences in translucency. Keep intricate structural features clearly defined through
careful tile placement rather than simplifying them.

Present the sculpture as a contemporary luxury editorial still life against a seamless warm ivory or soft neutral
background.

Use crisp directional studio lighting to create sparkling highlights, tiny reflections, dimensional shadows, and luminous
color variations across the tiles.

The final image should feel artistic, modern, tactile, collectible, vibrant, photographic, and meticulously handcrafted.
No typography, logos, labels, branding, or additional decorative objects.
```

## Usage Notes

Replace [INSERT OBJECT] with a concrete object that has a recognizable silhouette. The examples use a vintage instant camera as the sample object.

The example image shown for this file uses made-up input details so the prompt can be previewed without a real upload.
