# Jelly Object

![Jelly Object example](../../../examples/prompts/surreal-still-life/072-surreal-still-life-jelly-object.png)

## Prompt

```text
Translucent Jelly Object

Create an ultra-realistic soft jelly sculpture in the form of [INSERT OBJECT]. Preserve the object’s recognizable
silhouette, proportions, structure, defining features, and key details so it remains immediately identifiable, while
transforming every visible component into soft, wobbly gelatin.

Craft the object from thick, juicy, brightly colored jelly with slightly cloudy translucency. Make the material
unmistakably soft and flexible rather than hard or glass-like. Show gentle sagging under its own weight, softly
rounded edges, subtle bulging, compressed areas where pieces touch, tiny dents, delicate ripples, and slight irregular
deformation.

Include suspended micro-bubbles, faint internal waves, uneven thickness, moisture droplets, and a luscious wet
gelatin sheen. Allow light to glow softly through thinner sections while thicker areas appear richer, cloudier, and more
saturated.

Give delicate or projecting components a subtle droop or bend, as though the entire object could jiggle when touched.
The base should gently flatten and spread where the jelly rests on the surface.

Present it against a seamless, bright contrasting colored background such as vivid pink, electric blue, sunny yellow,
saturated coral, or vibrant turquoise.

Use directional studio lighting, luminous backlighting, glowing edges, soft highlights, transmitted color, and diffused
dimensional shadows.

The final image should feel squishy, jiggly, juicy, playful, tactile, photographic, and unmistakably gelatinous. Avoid
glass, crystal, resin, acrylic, plastic, gummy candy, or hard-candy appearances. No typography, logos, labels,
branding, packaging, or additional decorative objects.
```

## Usage Notes

Replace [INSERT OBJECT] with a concrete object that has a recognizable silhouette. The examples use a vintage instant camera as the sample object.

The example image shown for this file uses made-up input details so the prompt can be previewed without a real upload.
