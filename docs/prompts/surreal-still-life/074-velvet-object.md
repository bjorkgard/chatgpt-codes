# Velvet Object

![Velvet Object example](../../../examples/prompts/surreal-still-life/074-surreal-still-life-velvet-object.png)

## Prompt

```text
Create an ultra-realistic sculptural version of [INSERT OBJECT] completely wrapped and formed from luxurious
velvet. Preserve the object’s recognizable silhouette, proportions, structure, defining features, and key visual details
so it remains immediately identifiable, while transforming every visible component into rich, dimensional textile.

Cover the entire form in dense, plush velvet with a soft directional nap and exceptional tactile detail. Show realistic
variations where the fibers catch the light, shifting naturally between luminous highlights and deep saturated
shadows. Include subtle changes in pile direction, gentle compression, faint brushing marks, delicate seams, tailored
edges, tiny folds, and softly padded contours.

Use a sophisticated saturated color such as emerald green, ruby red, deep sapphire, plum, cobalt, or rich magenta.
Keep intricate features carefully constructed from velvet rather than simplifying them, using precise stitching and
miniature fabric-covered details where necessary.

Present the sculpture as a luxurious contemporary editorial still life against a seamless contrasting colored
background that clearly separates the silhouette.

Use refined directional studio lighting to emphasize the velvet’s characteristic sheen, dimensional pile, rich color
variations, soft shadows, and tactile depth.

The final image should feel sumptuous, surreal, elegant, tactile, fashion-forward, photographic, and meticulously
handcrafted. No typography, logos, labels, branding, packaging, or additional decorative objects. 4:5
```

## Usage Notes

Replace [INSERT OBJECT] with a concrete object that has a recognizable silhouette. The examples use a vintage instant camera as the sample object.

The example image shown for this file uses made-up input details so the prompt can be previewed without a real upload.
