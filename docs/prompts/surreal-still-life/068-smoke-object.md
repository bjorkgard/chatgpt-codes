# Smoke Object

![Smoke Object example](../../../examples/prompts/surreal-still-life/068-surreal-still-life-smoke-object.png)

## Prompt

```text
Create an ultra-realistic ethereal sculpture in the form of [INSERT OBJECT], constructed entirely from swirling,
dimensional smoke. Preserve the object’s recognizable silhouette, proportions, structure, defining features, and key
visual details so it remains immediately identifiable, while transforming every visible component into suspended
curling vapor.

Build the form from dense layers of soft white and pale gray smoke, with translucent wisps, billowing folds, delicate
tendrils, feathery edges, and intricate swirling currents. Keep the central structure relatively dense and defined while
allowing the outer edges to gradually dissolve into thin drifting ribbons of vapor.

Recreate smaller features through concentrated streams and carefully shaped curls of smoke rather than solid
materials. Add subtle internal turbulence, overlapping transparent layers, tiny pockets of negative space, and graceful
wisps escaping upward and outward.

Present the sculpture against a seamless bold colored background, such as cobalt blue, saturated coral, vivid pink,
deep purple, or rich turquoise, creating dramatic separation from the pale smoke.

Use cinematic directional lighting, luminous backlighting, subtle volumetric glow, soft shadows, and delicate highlights
illuminating individual wisps.

The final image should feel mysterious, weightless, surreal, elegant, photographic, dimensional, and fleeting, as
though the recognizable object could dissolve at any moment. No typography, logos, labels, branding, flames, or
additional decorative objects.
```

## Usage Notes

Replace [INSERT OBJECT] with a concrete object that has a recognizable silhouette. The examples use a vintage instant camera as the sample object.

The example image shown for this file uses made-up input details so the prompt can be previewed without a real upload.
