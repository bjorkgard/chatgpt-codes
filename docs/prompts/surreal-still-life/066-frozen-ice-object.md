# Frozen Ice Object

![Frozen Ice Object example](../../../examples/prompts/surreal-still-life/066-surreal-still-life-frozen-ice-object.png)

## Prompt

```text
Create an ultra-realistic frozen ice sculpture in the form of a [INSERT OBJECT]. Preserve the object’s recognizable
silhouette, proportions, structure, defining features, and key visual details so it is immediately identifiable, while
translating every element into crystal-clear sculpted ice.

Make the ice exceptionally realistic and dimensional, with transparent and semi-transparent areas, subtle cloudy
inclusions, suspended micro-bubbles, delicate internal fractures, fine stress cracks, frosted edges, and naturally
uneven frozen textures. Add tiny beads of condensation and melting droplets across the surface, with a small amount
of water collecting naturally beneath the object.

Keep intricate features beautifully formed in ice rather than simplifying them. Allow thicker sections to appear slightly
cloudy while thin edges glow with luminous transparency.

Present the object as a sophisticated high-fashion editorial still life against a seamless complimentary solid color
background. Use a bold, saturated color that strongly contrasts with the clear ice.

Illuminate it with crisp directional studio lighting, dramatic refraction, sparkling highlights, luminous edges, realistic
reflections, subtle caustic light patterns, and a refined grounding shadow.

The final image should feel modern, luxurious, surreal, photographic, and meticulously crafted, with exceptional
clarity and realistic frozen detail. No typography, logos, labels, or additional objects.
```

## Usage Notes

Replace [INSERT OBJECT] with a concrete object that has a recognizable silhouette. The examples use a vintage instant camera as the sample object.

The example image shown for this file uses made-up input details so the prompt can be previewed without a real upload.
