# Realistic Cake

![Realistic Cake example](../../../examples/prompts/surreal-still-life/065-surreal-still-life-realistic-cake.png)

## Prompt

```text
Create an ultra-realistic sculpted cake in the form of [INSERT OBJECT]. Preserve the object’s recognizable
silhouette, proportions, structure, defining features, characteristic colors, materials, textures, and key visual details so
it is immediately identifiable.

Recreate every visible element as convincing edible craftsmanship using fondant, modeling chocolate, buttercream,
sugar work, piped details, and sculpted decorations. Translate the object’s original materials and textures into
sophisticated edible equivalents while maintaining a remarkably realistic appearance.

Add one large realistic bite from a natural outer edge, revealing that the object is secretly cake. Show several layers
of fluffy golden vanilla sponge separated by generous bands of colorful fruit jam and creamy frosting. Create an
irregular bitten edge with compressed sponge, frosting smears, loose crumbs, and a few tiny cake pieces scattered
naturally below.

Keep the remainder of the object completely intact and pristine, creating a striking illusion between realistic object
and edible interior.

Present it as a high-fashion luxury editorial still life against a seamless, crisp white background. Use sophisticated
studio composition, clean directional lighting, refined soft shadows, subtle depth of field, immaculate styling, crisp
focus, and exceptional texture detail.

The final image should feel modern, elevated, minimalist, playful, photorealistic, and genuinely edible. Center the
object with generous white negative space. No text, logos, branding, props, hands, or additional objects.
```

## Usage Notes

Replace [INSERT OBJECT] with a concrete object that has a recognizable silhouette. The examples use a vintage instant camera as the sample object.

The example image shown for this file uses made-up input details so the prompt can be previewed without a real upload.

The example image uses a vintage instant camera as the inserted object.
