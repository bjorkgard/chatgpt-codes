# Marble Object

![Marble Object example](../../../examples/prompts/surreal-still-life/073-surreal-still-life-marble-object.png)

## Prompt

```text
Create an ultra-realistic carved marble sculpture in the form of [INSERT OBJECT]. Preserve the object’s
recognizable silhouette, proportions, structure, defining features, and key visual details so it remains immediately
identifiable, while transforming every visible component into luxurious natural stone.

Sculpt the object from creamy white marble with dramatic flowing veins of charcoal gray, soft taupe, smoky beige,
and subtle mineral variations. Allow the natural veining to travel organically across curves, edges, seams, and
individual components, wrapping continuously around the form as though carved from a single extraordinary block of
stone.

Give the marble realistic weight and depth with polished surfaces, softly rounded carved edges, subtle stone pores,
tiny mineral inclusions, faint imperfections, delicate variations in translucency along thin areas, and occasional finely
chiseled details. Keep intricate structural features precisely carved rather than simplified.

Present the sculpture as a sophisticated contemporary gallery still life against a seamless warm ivory, pale sand,
muted terracotta, or deep charcoal background that creates elegant separation from the stone.

Use refined directional studio lighting, soft sculptural shadows, controlled highlights, subtle reflections, and crisp
dimensional detail.

The final image should feel monumental, timeless, minimal, luxurious, tactile, photographic, and meticulously
handcrafted. No typography, logos, labels, branding, pedestals, or additional decorative objects.
```

## Usage Notes

Replace [INSERT OBJECT] with a concrete object that has a recognizable silhouette. The examples use a vintage instant camera as the sample object.

The example image shown for this file uses made-up input details so the prompt can be previewed without a real upload.
