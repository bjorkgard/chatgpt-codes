# Made Of Glass

![Made Of Glass example](../../../examples/prompts/surreal-still-life/064-surreal-still-life-made-of-glass.png)

## Prompt

```text
Create an ultra-realistic blown-glass sculpture in the form of [INSERT OBJECT].
Preserve the object’s recognizable silhouette, proportions, structure, defining features,
and key visual details so it remains immediately identifiable, while transforming every
visible component into transparent sculpted glass.

Craft the entire form from crystal-clear glass with realistic thickness, smooth polished
surfaces, rounded edges, and subtle handcrafted irregularities. Include tiny suspended
air bubbles, faint internal ripples, delicate distortions, slight variations in thickness, and
occasional barely visible flow lines created during forming.

Make intricate features convincingly sculpted from glass rather than simplified. Allow
thicker sections to produce stronger optical distortion while thinner edges appear
luminous and exceptionally clear. Create realistic refraction, reflections, magnification,
overlapping transparency, and subtle spectral highlights where light passes through
curved surfaces.

Present the sculpture as a sophisticated contemporary editorial still life against a
seamless bold colored background, such as cobalt blue, coral, vivid pink, emerald, or
golden yellow.

Use crisp directional studio lighting, luminous rim highlights, realistic caustic patterns,
controlled reflections, soft shadows, and brilliant refracted light.

The final image should feel pristine, delicate, luxurious, surreal, dimensional,
photographic, and meticulously handcrafted. No typography, logos, labels, branding,
cracks, frost, liquid, or additional decorative objects.
```

## Usage Notes

Replace [INSERT OBJECT] with a concrete object that has a recognizable silhouette. The examples use a vintage instant camera as the sample object.

The example image shown for this file uses made-up input details so the prompt can be previewed without a real upload.
