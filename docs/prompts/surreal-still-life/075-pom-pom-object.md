# Pom-Pom Object

![Pom-Pom Object example](../../../examples/prompts/surreal-still-life/075-surreal-still-life-pom-pom-object.png)

## Prompt

```text
Create an ultra-realistic sculptural version of [INSERT OBJECT] constructed entirely from thousands of individual
soft, fluffy craft pom-poms. Preserve the object’s recognizable silhouette, proportions, structure, defining features,
and key visual details so it remains immediately identifiable.

Cover every visible component with densely arranged, clearly separate spherical pom-poms in varied sizes. Use
larger pom-poms across broad surfaces and tiny individual pom-poms to precisely form edges, seams, curves,
openings, laces, hardware, and intricate details.

Each pom-pom must look like a classic fluffy craft pom-pom made from hundreds of extremely fine, straight synthetic
fibers radiating outward from a dense center. Show fuzzy halos, wispy stray fibers, feathery edges, slight
compression where pom-poms touch, subtle size irregularities, and realistic overlapping. Individual pom-poms should
remain visibly distinguishable rather than merging into a continuous textile surface.

Use a playful, sophisticated palette of saturated brights, soft pastels, and complementary colors arranged naturally
across the form.

Present the sculpture against a seamless bold contrasting colored background with crisp directional studio lighting,
soft shadows, shallow depth of field, and exceptional macro fiber detail.

The result should feel plush, whimsical, modern, tactile, photographic, and meticulously handcrafted. Absolutely no
crochet, knitting, woven fabric, yarn loops, chenille, tufting, braided fibers, stitched textures, or knitted patterns. No
typography, logos, labels, packaging, or additional objects.
```

## Usage Notes

Replace [INSERT OBJECT] with a concrete object that has a recognizable silhouette. The examples use a vintage instant camera as the sample object.

The example image shown for this file uses made-up input details so the prompt can be previewed without a real upload.
