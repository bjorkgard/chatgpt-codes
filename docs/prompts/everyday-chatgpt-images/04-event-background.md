# Event Background

![Event background example](../../../examples/prompts/everyday-chatgpt-images/04-event-background.png)

## Prompt

```text
/wideframe + /goldenhour + /softlight + /negativespace
Create an event invitation background for [event type] in [setting]. Use warm golden-hour atmosphere, a wide frame, elegant environmental detail, and generous open space in the [top/center/side] for event details to be added later. Keep the scene welcoming and realistic. Vertical format. No generated text, logos, watermarks, distorted people, or distracting clutter.
```

## Usage Notes

This is strongest as a text-free background for invitations or announcements. Specify where the open space belongs so the generated image leaves room for event details.
