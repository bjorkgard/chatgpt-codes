# Presentation Explainer

![Presentation explainer example](../../../examples/prompts/everyday-chatgpt-images/05-presentation-explainer.png)

## Prompt

```text
/isometric + /explodedview + /blueprint + /visualwiki
Create a clean presentation visual explaining [system, process, or concept]. Show the major parts as separated but connected modules, using an isometric blueprint style, simple arrows, and clear hierarchy. Keep the background light and uncluttered. Use short placeholder labels only if needed, or leave labels blank for editing in slides. Wide presentation format. No tiny unreadable text, logos, or decorative filler.
```

## Usage Notes

Use this when a slide needs a structured visual before exact labels are finalized. For text-heavy decks, generate the diagram with blank label spaces and add final labels in the slide editor.
