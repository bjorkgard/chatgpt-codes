# Product Listing Hero

![Product listing hero example](../../../examples/prompts/everyday-chatgpt-images/03-product-listing-hero.png)

## Prompt

```text
/producthero + /packshot + /softlight + /negativeprompt
Create a clean product listing hero image for [product]. Keep the product shape, color, label, and material accurate. Use a simple studio surface, soft commercial lighting, subtle shadow, and enough breathing room for cropping. Square product image suitable for ecommerce. No fake text, altered branding, extra props, watermarks, hands, or background clutter.
```

## Usage Notes

Use this for marketplace or shop images where the product needs to stay accurate. If the product has a label, packaging, logo, or specific finish, call those out explicitly.
