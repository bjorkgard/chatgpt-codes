# Profile Photo

![Profile photo example](../../../examples/prompts/everyday-chatgpt-images/01-profile-photo.png)

## Prompt

```text
/eyelevel + /mediumshot + /softlight + /35mm
Create a natural work profile photo of [person] in [setting]. Frame from the chest or waist up at eye level, with soft window-like light, clean background separation, realistic skin texture, and calm approachable expression. Use [brand or wardrobe colors] subtly. Square profile image. No text, logos, extra people, distorted hands, or artificial skin smoothing.
```

## Usage Notes

Use this when the face should feel natural and professional without becoming a glossy studio headshot. Keep the background simple, and name any clothing, color, or identity details that must be preserved.
