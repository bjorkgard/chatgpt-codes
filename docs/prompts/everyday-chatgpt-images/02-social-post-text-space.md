# Social Post Text Space

![Social post text space example](../../../examples/prompts/everyday-chatgpt-images/02-social-post-text-space.png)

## Prompt

```text
/ruleofthirds + /negativespace + /softlight + /coverstory
Create a vertical social post background showing [subject] in [setting or action]. Place the subject on the [left/right/lower third] and leave clean negative space on the [opposite area] for a headline that will be added later. Use [mood colors], soft flattering light, and a polished editorial composition. No generated text, logos, clutter, or extra subjects.
```

## Usage Notes

This prompt works best when the subject placement and empty area are specified clearly. Add the headline later in a design tool when spelling and exact layout matter.
