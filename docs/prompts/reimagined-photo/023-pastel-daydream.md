# Pastel Daydream

![Pastel Daydream example](../../../examples/prompts/reimagined-photo/023-reimagined-photo-pastel-daydream.png)

## Prompt

```text
Pastel Dreamy 3D Render**Reference Image Required:** Upload a reference image. Transform it into a whimsical
pastel 3D fantasy world, using the reference as inspiration for the subject, composition, and overall personality rather
than recreating it exactly. Preserve the original camera angle, pose, perspective, framing, horizon, subject placement,
and major objects so the scene remains instantly recognizable.

Stylize everything with smooth, rounded, sculpted forms, soft silhouettes, oversized proportions, and simplified
shapes. Enhance the existing environment with subtle fantasy details such as pastel flowers, flowering vines,
blossoms, floating petals, and fluffy clouds that naturally complement the scene without replacing or overwhelming it.
Avoid introducing large new buildings, landmarks, or landscapes.

Render people, clothing, trees, roads, buildings, vehicles, animals, and accessories with velvety matte-satin
materials, soft gradients, gentle diffuse reflections, and a handcrafted 3D appearance. Use a soothing palette of blush
pink, lavender, peach, buttercream, mint, baby blue, ivory, soft sage, and pale aqua.

Illuminate the scene with warm golden-hour light, soft ambient glow, atmospheric haze, delicate volumetric rays,
dreamy bloom, and gentle rim lighting. Maintain layered depth, cinematic depth of field, graceful curves, and an airy
sense of space. The final image should feel magical, comforting, nostalgic, and serene while remaining clearly
recognizable as the original photograph, beautifully transformed into a dreamy pastel fantasy world.
```

## Usage Notes

Use these when you have a reference photo and want the same subject reinterpreted in a new artistic style. Keep identity, pose, and composition instructions specific when those details matter.

The example image shown for this file uses made-up input details so the prompt can be previewed without a real upload.
