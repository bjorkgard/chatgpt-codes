# Classic Portrait Studio

![Classic Portrait Studio example](../../../examples/prompts/reimagined-photo/026-reimagined-photo-classic-portrait-studio.png)

## Prompt

```text
Transform the uploaded image into a timeless monochrome portrait captured in a
classic portrait booth. Use the reference primarily for the subject’s identity, expression,
and overall character rather than recreating the original composition. Freely reinterpret
the clothing, hairstyle, pose, framing, and background to create an authentic vintage
studio portrait.

Replace the original environment with a simple floor-to-ceiling fabric backdrop featuring
soft vertical folds that completely fills the frame. Convert the image to rich
black-and-white with subtle warm silver tones, luminous skin, deep blacks, smooth
midtones, and gentle tonal transitions.

Light the subject with classic portrait lighting using a large soft key light, gentle fill, and
delicate shadow falloff for a flattering, cinematic look. Encourage relaxed, candid
expressions such as a soft smile, laughter, thoughtful eye contact, looking away, resting
the chin on a hand, adjusting clothing, or brushing back hair.

Dress the subject in timeless knit sweaters, turtlenecks, crewnecks, or other
understated textured garments without logos, graphics, or bold patterns. Compose the
portrait as waist-up, chest-up, or close head-and-shoulders with generous negative
space.

Finish with subtle analog character including fine film grain, faint dust, tiny scratches,
gentle vignetting, slight lens softness, mild tonal fading, and delicate paper texture. The
result should feel archival, intimate, expressive, and beautifully preserved.
```

## Usage Notes

Use these when you have a reference photo and want the same subject reinterpreted in a new artistic style. Keep identity, pose, and composition instructions specific when those details matter.

The example image shown for this file uses made-up input details so the prompt can be previewed without a real upload.
