# Flat Cel-painted Anime

![Flat Cel-painted Anime example](../../../examples/prompts/reimagined-photo/004-reimagined-photo-flat-cel-painted-anime.png)

## Prompt

```text
Upload a clear reference photo. Use it as the identity reference, faithfully preserving the person’s recognizable facial
features, face shape, eye shape, eye color, smile, skin tone, hairstyle, hair color, clothing, pose, composition, camera
angle, lighting direction, background, and overall appearance. Do not add, remove, or rearrange scene
elements—the only transformation should be the artistic style.

Transform the subject into a timeless hand-drawn anime character inspired by traditional cel-painted animation.
Simplify facial features into clean, elegant shapes while preserving identity. Use expressive yet naturally proportioned
eyes, subtle noses, soft smiles, crisp ink linework, and classic cel shading with large, flat areas of color.

Render the entire scene as a traditional cel-animation background with simplified shapes, clean edges, minimal
texture, restrained detail, subtle atmospheric perspective, and a limited color palette. Use flat painted surfaces with
little or no visible brushwork, gradients, or watercolor effects.

Light the scene with soft natural daylight, clean directional lighting, and simple two- or three-tone cel shading with
crisp graphic shadows.

Be sure to add some subtle atmospheric details, such as drifting petals, butterflies, birds, or floating leaves.

Avoid photorealism, CGI, watercolor, gouache textures, painterly blending, glossy rendering, hyper-detailed anatomy,
harsh contrast, neon colors, excessive fantasy effects, logos, text, or copyrighted characters. Emphasize painted
animation cels, acetate artwork, flat poster colors, clean contour lines, minimal rendering, graphic shapes, and a
classic 1990s anime aesthetic.
```

## Usage Notes

Use these when you have a reference photo and want the same subject reinterpreted in a new artistic style. Keep identity, pose, and composition instructions specific when those details matter.

The example image shown for this file uses made-up input details so the prompt can be previewed without a real upload.
