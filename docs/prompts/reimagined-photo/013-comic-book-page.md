# Comic Book Page

![Comic Book Page example](../../../examples/prompts/reimagined-photo/013-reimagined-photo-comic-book-page.png)

## Prompt

```text
Upload a reference image. Transform the uploaded image into a dramatic comic book / graphic novel illustration,
using the reference primarily as inspiration for the subject, composition, and overall scene rather than something to
recreate exactly. Lean heavily into the illustrated style, allowing the artwork to reinterpret facial features, clothing,
lighting, textures, and proportions while keeping the subject generally recognizable. Create the image with bold
expressive black ink outlines, dynamic line weight, hand-drawn brush strokes, cross-hatching, halftone dot shading,
printed comic textures, subtle paper grain, graphic shadows, simplified forms, and high-contrast cinematic lighting.
Eliminate all traces of photorealism so the final result immediately reads as professionally illustrated comic art. Use a
rich, saturated comic-book color palette featuring deep blacks, vibrant reds, electric blues, golden yellows, emerald
greens, dramatic purple shadows, and warm skin tones, enhanced with subtle print imperfections and halftone
transitions that mimic high-quality comic printing. Recompose the scene where needed with dynamic camera angles,
foreshortening, strong silhouettes, diagonal compositions, exaggerated perspective, and action-oriented posing rather
than simply tracing the original photograph. Present the artwork as an authentic comic page featuring multiple panels
with bold borders, angled transitions, large hero panels, supporting close-ups, and environmental establishing shots
arranged to create visual storytelling. Incorporate authentic comic elements such as speech bubbles, thought
bubbles, caption boxes, and integrated sound effects like BAM!, POW!, CRASH!, WHOOSH!, BOOM!, and THWACK!
wherever they naturally enhance the scene. Amplify movement with speed lines, impact bursts, motion streaks, flying
debris, energy effects, and dramatic framing that create a sense of momentum and excitement. The overall goal is
not to faithfully reproduce the reference image but to transform it into a bold, cinematic, highly stylized page from a
premium modern graphic novel, with the artistic comic style taking clear priority over photographic accuracy.
```

## Usage Notes

Use these when you have a reference photo and want the same subject reinterpreted in a new artistic style. Keep identity, pose, and composition instructions specific when those details matter.

The example image shown for this file uses made-up input details so the prompt can be previewed without a real upload.
