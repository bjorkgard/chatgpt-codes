# Flat Vector Illustration

![Flat Vector Illustration example](../../../examples/prompts/reimagined-photo/009-reimagined-photo-flat-vector-illustration.png)

## Prompt

```text
Flat Vector Illustration Portrait

Upload a clear reference photo of yourself. Use the uploaded image only as a loose composition and subject
reference rather than a blueprint for faithfully recreating every detail. Preserve the overall pose, camera angle,
framing, silhouette, and the broad arrangement of the scene, but intentionally simplify the person, clothing,
background, and every object into a clean, modern flat vector illustration.

Lean fully into the graphic design aesthetic instead of realism. Reduce the subject to simple geometric shapes,
smooth curves, crisp edges, and bold, confident silhouettes. Facial features should be extremely minimal—small
eyes, simple eyebrows, a tiny nose, and a subtle mouth—with just enough information to communicate expression
rather than identity. Eliminate realistic skin texture, detailed hair strands, fabric folds, wrinkles, and fine accessories in
favor of large, readable shapes.

Reinterpret the entire environment as a stylized vector scene. Simplify buildings, trees, roads, furniture, water,
mountains, clouds, and other background elements into layered graphic forms with minimal detail and clean visual
hierarchy. Favor rounded shapes, repeating patterns, and elegant negative space over realism.

Use a harmonious palette of muted, slightly retro-inspired colors with broad areas of solid fills, subtle gradients only
where appropriate, and little to no visible texture. Avoid painterly effects, photographic lighting, realistic shadows, or
dimensional rendering. Instead, use simple flat shading and clean overlapping color blocks to create depth.

The finished illustration should feel like premium editorial vector artwork, modern infographic design, or a beautifully
crafted lifestyle illustration suitable for magazines, websites, posters, apps, branding, or motion graphics. It should
immediately read as a polished flat vector illustration—not a traced photograph or lightly stylized image—with
exceptional simplicity, clarity, and graphic appeal.
```

## Usage Notes

Use these when you have a reference photo and want the same subject reinterpreted in a new artistic style. Keep identity, pose, and composition instructions specific when those details matter.

The example image shown for this file uses made-up input details so the prompt can be previewed without a real upload.
