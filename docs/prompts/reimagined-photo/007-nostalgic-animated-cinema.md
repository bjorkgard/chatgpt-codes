# Nostalgic Animated Cinema

![Nostalgic Animated Cinema example](../../../examples/prompts/reimagined-photo/007-reimagined-photo-nostalgic-animated-cinema.png)

## Prompt

```text
Upload a clear reference photo. Use it as the identity and composition reference while faithfully preserving the
subject's recognizable facial features, face shape, eye shape, smile, skin tone, hairstyle, hair color, body proportions,
pose, clothing, accessories, camera angle, framing, lighting direction, environment, and emotional atmosphere so the
finished artwork is immediately recognizable as the same moment.

Transform the entire image into a timeless hand-painted animated film frame that feels crafted by skilled traditional
artists rather than generated digitally. Simplify every subject into elegant, expressive shapes with clean silhouettes,
gentle facial features, soft proportions, and subtle stylization while preserving the person's identity. Paint the entire
environment with rich handcrafted backgrounds, simplified forms, and carefully composed details that enhance the
storytelling without becoming overly realistic.

Use warm cinematic lighting, harmonious color palettes, painterly textures, soft brushwork, and restrained cel-style
shading with broad areas of color and gentle transitions. Let every tree, flower, building, sky, landscape, and object
feel lovingly painted by hand with slight artistic imperfections that celebrate traditional craftsmanship.

Favor warmth, nostalgia, simplicity, and emotional storytelling over photographic accuracy. Avoid photorealism,
watercolor blooms, vector graphics, heavy outlines, glossy rendering, 3D effects, excessive detail, or digital-looking
textures. The finished artwork should immediately read as a beautifully hand-painted frame from a classic animated
feature, with the artistic style taking clear priority over the original photograph.
```

## Usage Notes

Use these when you have a reference photo and want the same subject reinterpreted in a new artistic style. Keep identity, pose, and composition instructions specific when those details matter.

The example image shown for this file uses made-up input details so the prompt can be previewed without a real upload.
