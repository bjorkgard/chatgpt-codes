# Kawaii Pop Art

![Kawaii Pop Art example](../../../examples/prompts/reimagined-photo/017-reimagined-photo-kawaii-pop-art.png)

## Prompt

```text
Transform the uploaded photograph into a polished kawaii-inspired pop-art illustration while faithfully preserving the
subject's recognizable identity, facial features, expression, age, body proportions, skin tone, hairstyle, clothing,
accessories, pose, camera angle, composition, perspective, lighting direction, and overall scene. Use the reference
as the foundation, reimagining it only through the illustrated style rather than altering the subject or environment.

Render the artwork as a premium modern digital illustration with crisp linework, smooth cel-style shading, silky
gradients, rounded forms, simplified geometry, and polished vector-like surfaces. Slightly enlarge the eyes while
preserving their natural shape, add soft blush, glossy lips, expressive catchlights, delicate lashes, and luminous skin
gradients without losing the person's unique features.

Recreate the original background in the same layout, simplifying scenery into colorful illustrated forms with clean
contours and soft shading. Use a cheerful pastel palette of pinks, lavenders, blues, peaches, mint greens, buttery
yellows, and vibrant accents. Add playful hearts, stars, sparkles, flowers, bows, stickers, doodles, handwritten
accents.

The finished image should feel bright, charming, whimsical, and unmistakably handcrafted as a polished
kawaii-inspired pop-art illustration while remaining clearly recognizable as the original photograph.
```

## Usage Notes

Use these when you have a reference photo and want the same subject reinterpreted in a new artistic style. Keep identity, pose, and composition instructions specific when those details matter.

The example image shown for this file uses made-up input details so the prompt can be previewed without a real upload.
