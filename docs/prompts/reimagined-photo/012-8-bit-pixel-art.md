# 8-Bit Pixel Art

![8-Bit Pixel Art example](../../../examples/prompts/reimagined-photo/012-reimagined-photo-8-bit-pixel-art.png)

## Prompt

```text
Upload a clear reference image. Use it only as inspiration for the subject, mood, story,
and overall theme—not as a blueprint. Freely redesign the composition, camera angle,
perspective, environment, character placement, architecture, landscape, clothing,
props, objects, and lighting whenever it creates a stronger retro video game aesthetic.
The final artwork should feel like an original early home-console game level inspired by
the reference, never a pixelated copy.

Transform the scene into authentic handcrafted 8-bit pixel art with every pixel
intentionally placed by hand. Redesign all subjects as charming, iconic sprites with bold
silhouettes, simplified anatomy, expressive poses, and instantly recognizable forms.
Rebuild the environment using classic tile-based level design with modular terrain,
repeating tiles, and gameplay-inspired elements.

Imagine the world is fully playable. Add platforms, ladders, bridges, pathways, treasure
chests, collectible items, signs, fences, flowers, friendly characters, landmarks, and
other classic game-world elements where appropriate to enrich the scene.

Emulate the visual limitations of early home gaming systems using a restricted color
palette, bold saturated colors, crisp square pixels, strong contrast, and exceptional
readability. Avoid gradients, anti-aliasing, modern pixel-art effects, realistic lighting,
detailed textures, or photographic depth. Favor clean side-scrolling, top-down, or
isometric layouts with simplified silhouettes, minimal detail, balanced compositions, and
timeless retro charm.
```

## Usage Notes

Use these when you have a reference photo and want the same subject reinterpreted in a new artistic style. Keep identity, pose, and composition instructions specific when those details matter.

The example image shown for this file uses made-up input details so the prompt can be previewed without a real upload.
