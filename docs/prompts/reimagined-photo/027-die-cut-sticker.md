# Die-Cut Sticker

![Die-Cut Sticker example](../../../examples/prompts/reimagined-photo/027-reimagined-photo-die-cut-sticker.png)

## Prompt

```text
Upload a reference image. Transform it into a vibrant sticker-style illustration, using the
original primarily for the subject, composition, pose, and personality rather than
recreating it exactly. Freely simplify proportions, facial features, clothing, hairstyles,
objects, and scenery while keeping the subject recognizable. Prioritize a fun collectible
sticker aesthetic over realism.

Reimagine every visible element as a premium die-cut sticker with smooth illustrated
surfaces, bold graphic shapes, saturated colors, and clean, simplified forms. People
should become charming cartoon characters with oversized heads, expressive eyes,
rounded features, exaggerated smiles, and lively poses. Clothing should feature bold
color blocking with minimal folds, while hair becomes smooth sculpted shapes.

Simplify buildings, furniture, plants, animals, vehicles, food, and other objects into
playful illustrated forms with rounded geometry and friendly proportions. Surround every
major element with a thick white die-cut border and a bold black outline, varying sticker
sizes to create depth and visual rhythm.

Use bright colors, crisp contrast, subtle cel shading, soft gradients, small highlights, and
gentle shadows for slight dimensionality while maintaining a clean graphic look. Add
playful accents like stars, hearts, sparkles, arrows, swirls, lightning bolts, flowers,
confetti, or simple icons. Finish with a simplified illustrated background that preserves
the overall composition while feeling cheerful, bold, and unmistakably sticker-like.
```

## Usage Notes

Use these when you have a reference photo and want the same subject reinterpreted in a new artistic style. Keep identity, pose, and composition instructions specific when those details matter.

The example image shown for this file uses made-up input details so the prompt can be previewed without a real upload.
