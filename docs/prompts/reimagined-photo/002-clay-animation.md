# Clay Animation

![Clay Animation example](../../../examples/prompts/reimagined-photo/002-reimagined-photo-clay-animation.png)

## Prompt

```text
Transform the uploaded Reference Photo into a handcrafted clay animation scene while faithfully preserving the
subject's recognizable facial features, face shape, eye shape, eye color, smile, skin tone, hairstyle, hair color, and
overall appearance. Reimagine them as a charming miniature clay character with a warm, expressive personality.

Render the entire image as a handcrafted stop-motion clay world with soft sculpted textures, subtle fingerprints, tiny
tool marks, rounded forms, and gently imperfect edges that celebrate traditional craftsmanship. Give every object,
prop, and background element the same cohesive clay appearance.

While staying true to the background and scene, adjust the style this way: Use warm cinematic lighting, soft golden
highlights, rich earthy colors, and a cozy storybook atmosphere. Include expressive poses, playful movement,
detailed miniature sets, and carefully crafted props that bring the scene to life. Don't add elements that aren't there.

Avoid photorealism, glossy materials, digital-looking surfaces, or overly perfect geometry. The final image should feel
like a timeless handcrafted stop-motion production filled with warmth, charm, whimsy, and personality.
```

## Usage Notes

Use these when you have a reference photo and want the same subject reinterpreted in a new artistic style. Keep identity, pose, and composition instructions specific when those details matter.

The example image shown for this file uses made-up input details so the prompt can be previewed without a real upload.
