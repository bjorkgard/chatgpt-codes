# Cyberpunk Cinematic

![Cyberpunk Cinematic example](../../../examples/prompts/reimagined-photo/021-reimagined-photo-cyberpunk-cinematic.png)

## Prompt

```text
Upload a reference image. Transform the uploaded image into a cinematic futuristic cyberpunk scene, using the
reference primarily as inspiration for the subject, composition, and overall mood rather than something to recreate
exactly. Lean heavily into the cyberpunk aesthetic, freely reimagining facial features, clothing, hairstyle, environment,
lighting, camera angle, and surrounding architecture while keeping the subject generally recognizable. The finished
image should immediately feel like a frame from a high-budget futuristic science fiction film rather than an edited
photograph.

Place the subject inside a dense neon-lit megacity filled with towering skyscrapers, holographic billboards, glowing
signage, reflective glass, elevated walkways, futuristic architecture, and atmospheric urban density. Surround the
scene with rain-soaked streets, puddles reflecting colorful lights, drifting mist, steam vents, subtle fog, and distant
traffic to create depth and atmosphere.

Illuminate the scene using vibrant neon lighting in electric magenta, cyan, violet, crimson, teal, and deep blue. Create
dramatic rim lighting, glowing reflections, volumetric light beams, illuminated fog, and realistic wet surfaces that
scatter colored light throughout the environment.

Design clothing with a futuristic urban aesthetic featuring sleek jackets, tactical fabrics, layered streetwear, subtle
illuminated accents, metallic materials, and modern sci-fi silhouettes. Allow outfits to be completely reinterpreted to
better match the setting.

Use cinematic filmmaking techniques including shallow depth of field, realistic lens bloom, soft anamorphic flares,
subtle film grain, atmospheric perspective, and rich cinematic contrast. Compose the image with bold framing, strong
leading lines, and immersive environmental storytelling.

Render everything with photorealistic detail, lifelike skin, authentic materials, natural human anatomy, realistic
reflections, and production-quality visual effects. The final image should feel like a premium science fiction
blockbuster set in a dark neon metropolis filled with rain, glowing advertisements, holograms, and futuristic energy.
```

## Usage Notes

Use these when you have a reference photo and want the same subject reinterpreted in a new artistic style. Keep identity, pose, and composition instructions specific when those details matter.

The example image shown for this file uses made-up input details so the prompt can be previewed without a real upload.
