# Mauve Mood

![Mauve Mood example](../../../examples/prompts/fashion-makeup/081-fashion-makeup-mauve-mood.png)

## Prompt

```text
Upload a clear, front-facing selfie in natural lighting. Preserve the subject’s recognizable identity, facial features, face
shape, skin tone, eye color, expression, hairstyle length, and overall likeness while applying a sophisticated
monochromatic mauve beauty transformation.

Create a realistic soft-satin complexion with lightweight coverage, visible skin texture, and natural dimension. Subtly
minimize redness, uneven tone, blemishes, and under-eye darkness. Add cool-neutral contour beneath the
cheekbones, jawline, temples, and nose. Sweep diffused dusty mauve-rose blush across the upper cheeks toward
the temples with a subtle touch over the nose. Add restrained pearlescent highlights.

Create softly smoky eyes using dusty mauve, rosy taupe, muted plum, mauve-brown, and soft lavender-gray,
blending seamlessly with diffused edges. Deepen the outer corners with muted plum and mauve-brown. Sweep
mauve along the lower lash line and add subtle champagne-mauve shimmer to the lids and inner corners. Finish with
soft brown liner, wispy lashes, mascara, and feathered brows.

Define the lips with muted mauve-rose liner blended into creamy dusty-mauve satin color. Add subtle center gloss.

Be sure to change the hair Style to a sleek, glossy, center-parted hair tucked behind the ears. Use soft diffused
daylight. Keep the result photorealistic, romantic, refined, modern, and editorial.
```

## Usage Notes

Use these with a clear front-facing selfie in natural light. The example images use a fictional subject where the original prompt expects an uploaded photo.

The example image shown for this file uses made-up input details so the prompt can be previewed without a real upload.
