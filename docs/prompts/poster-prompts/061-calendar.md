# Calendar

![Calendar example](../../../examples/prompts/poster-prompts/061-poster-prompts-calendar.png)

## Prompt

```text
Upload a clear reference selfie and enter the year: **[2027]**. Create a single-page, 12-month wall calendar in a
whimsical hand-painted storybook style using watercolor washes, delicate ink lines, soft gouache textures, pastel
colors, and charming botanical details.

Preserve the subject’s recognizable identity, facial features, proportions, and overall likeness throughout all twelve
illustrations. Give each month unique seasonal clothing, hairstyles, accessories, a variety of poses, body angles,
hand placement, gaze directions, and compositions. Vary standing, sitting, walking, leaning, reading, gathering
flowers, holding props, and interacting naturally with the environment. Alternate front, profile, three-quarter,
over-the-shoulder, full-body, seated, and environmental views.

Create distinct seasonal scenes: January—snow; February—romantic florals; March—greenery; April—blossoms and
rain; May—flower meadow; June—seaside; July—sunny travel; August—sunflowers; September—books and early
autumn; October—pumpkins and whimsical Halloween styling; November—cozy autumn streets; December—festive
lights, ornaments, and snow.

Place **[2027]** prominently at the top. Accurately calculate every month’s dates, weekday alignment, month length,
and leap-year status. Keep calendar grids clean and readable with generous white space. Ensure artwork never
obscures dates. Create a cohesive, feminine, timeless, printable composition resembling a romantic illustrated
journal.
```

## Usage Notes

Replace bracketed inputs such as season, month, destination, activity count, or zodiac sign before generating.

The example image shown for this file uses made-up input details so the prompt can be previewed without a real upload.
