# Timeless Birthday

![Timeless Birthday example](../../../examples/prompts/selfie-transformation/045-selfie-transformation-timeless-birthday.png)

## Prompt

```text
Create a deeply emotional, museum-quality birthday portrait that places the same person face-to-face with their
younger self. Using the uploaded reference selfie photo, create a perfectly symmetrical vertical 4:5 split-screen with a
razor-clean center divide. The left side shows the subject as a child celebrating a birthday, while the right shows them
today. Preserve the subject's recognizable identity by creating a believable younger version with matching facial
features, expression, and overall appearance. If a childhood birthday photo is provided, use it as inspiration;
otherwise, generate an authentic era-appropriate birthday scene.

The child and adult should make direct eye contact across the divide with warm, reflective expressions. Create one
continuous birthday cake spanning both halves, perfectly aligned in perspective, lighting, and decorations. Display the
subject's current age [INSERT AGE] as one continuous set of numeral candles by placing the first digit on the
childhood side and the remaining digit(s) on the adult side.

Match the framing, pose, camera angle, and lighting so both halves feel like one uninterrupted moment. Keep the
scene minimal with only the subject, shared cake, table, and softly blurred background. Style the childhood side as a
vintage family photograph and the adult side as warm cinematic editorial photography. Add elegant serif typography
showing the appropriate year and birthday on each side. The final image should feel timeless, nostalgic, seamless,
and worthy of being framed as a treasured family heirloom.
```

## Usage Notes

Use these with a clear selfie or portrait reference. The example images use a fictional subject where the original prompt expects an uploaded photo.

The example image shown for this file uses made-up input details so the prompt can be previewed without a real upload.
