# Refrigerator POV

![Refrigerator POV example](../../../examples/prompts/selfie-transformation/047-selfie-transformation-refrigerator-pov.png)

## Prompt

```text
Refrigerator POV Snapshot

Upload a selfie of headshot photo. Use it only as inspiration for the subject's recognizable facial features, expression,
and personality while freely reinterpreting clothing, hairstyle, colors, accessories, kitchen design, groceries, framing,
and composition. Prioritize the immersive refrigerator-camera perspective over faithfully recreating the original image.

Place the camera deep inside an open refrigerator, creating the illusion that the viewer is sitting on a shelf looking
outward. Use an ultra-wide 18–24mm lens with subtle barrel distortion. Keep the face naturally proportioned and
centered. The subject reaches toward the camera with realistic anatomy, avoiding oversized hands, stretched arms,
warped joints, or exaggerated perspective.

Surround the frame with casually arranged groceries including produce, berries, drinks, jars, condiments, cheese,
leftovers, and containers that create depth without blocking the subject. Show a warm, modern kitchen beyond the
refrigerator with soft pendant lighting and clean cabinetry.

Illuminate the subject with cool refrigerator light contrasted by warm ambient kitchen light. Capture a relaxed, candid
moment with natural body language. Add subtle photographic imperfections including faint digital noise, slight edge
softness, tiny lens smudges, mild motion blur, realistic depth of field, and gentle exposure variation so the image feels
like an authentic refrigerator POV photograph.
```

## Usage Notes

Use these with a clear selfie or portrait reference. The example images use a fictional subject where the original prompt expects an uploaded photo.

The example image shown for this file uses made-up input details so the prompt can be previewed without a real upload.
