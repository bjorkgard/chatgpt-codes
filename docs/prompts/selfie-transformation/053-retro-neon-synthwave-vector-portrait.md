# Retro Neon Synthwave Vector Portrait

![Retro Neon Synthwave Vector Portrait example](../../../examples/prompts/selfie-transformation/053-selfie-transformation-retro-neon-synthwave-vector-portrait.png)

## Prompt

```text
Upload one clear selfie. Transform it into a premium retro synthwave vector portrait inspired by 1980s outrun
aesthetics, neon editorial posters, and cinematic graphic design while faithfully preserving the subject's recognizable
identity, including facial structure, age, skin tone, hairstyle, expression, body proportions, accessories, and overall
likeness.

Always expand the composition into a natural waist-up portrait. Reconstruct the shoulders, torso, arms, and clothing
seamlessly, preserving the original outfit whenever possible. If parts of the clothing are hidden, intelligently extend the
visible garments while maintaining their style, colors, fabrics, neckline, and sleeves.

Render the artwork as a polished vector illustration with crisp contours, clean geometric shapes, smooth cel-style
shading, elegant gradients, and simplified graphic forms. Preserve realistic facial proportions while eliminating
photographic textures.

Illuminate the portrait with vibrant synthwave lighting using warm oranges, magentas, pinks, purples, deep blues, and
subtle cyan rim light. Place the subject against a minimalist neon sunset with layered gradients, geometric sun,
distant mountains, palm trees, or an ocean horizon.

Center the subject in a relaxed, confident pose with refined editorial composition. The finished artwork should
resemble a luxury album cover or premium retro-futuristic poster with bold contrast, cinematic depth, and timeless
neon style.
```

## Usage Notes

Use these with a clear selfie or portrait reference. The example images use a fictional subject where the original prompt expects an uploaded photo.

The example image shown for this file uses made-up input details so the prompt can be previewed without a real upload.
