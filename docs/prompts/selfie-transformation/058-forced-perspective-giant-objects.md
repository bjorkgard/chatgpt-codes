# Forced Perspective Giant Objects

![Forced Perspective Giant Objects example](../../../examples/prompts/selfie-transformation/058-selfie-transformation-forced-perspective-giant-objects.png)

## Prompt

```text
Forced Perspective Giant Objects Portrait

Object 1: (Insert)

Object 2: (Insert)

Upload a reference photo. Use it as inspiration for the subject's recognizable identity, facial features, hairstyle,
expression, and overall presence while freely reimagining the wardrobe, pose, lighting, environment, composition,
and colors. Prioritize a convincing forced-perspective illusion over faithfully recreating the original image.

Place the subject centered on a long, symmetrical street, pedestrian avenue, or quiet road with strong leading lines
and an uncluttered background. Avoid signs, monuments, traffic, parked cars, or other distractions so the perspective
effect remains the focal point.

Photograph from a low angle using an ultra-wide lens. The subject stands naturally with both arms extended straight
outward at shoulder height, looking confidently toward the camera. Keep the body centered and symmetrical.

Position Object 1 in one hand and Object 2 in the other using forced perspective so both appear many times larger
than the subject while still looking naturally held. Let the oversized objects extend beyond the edges of the frame and
dominate the composition without appearing distorted.

Use soft natural daylight, realistic colors, subtle shadows, and generous negative space. The finished image should
feel clean, balanced, modern, and visually striking with the giant-object illusion as the unmistakable focus.
```

## Usage Notes

Use these with a clear selfie or portrait reference. The example images use a fictional subject where the original prompt expects an uploaded photo.

The example image shown for this file uses made-up input details so the prompt can be previewed without a real upload.
