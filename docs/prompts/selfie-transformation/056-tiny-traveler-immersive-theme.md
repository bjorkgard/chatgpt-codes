# Tiny Traveler Immersive Theme

![Tiny Traveler Immersive Theme example](../../../examples/prompts/selfie-transformation/056-selfie-transformation-tiny-traveler-immersive-theme.png)

## Prompt

```text
Tiny Traveler Immersive Theme Portrait

[THEME]

Upload one clear selfie. Preserve the subject's recognizable identity, facial features, body proportions, skin tone,
hairstyle, expression, and overall likeness. Shrink the subject so they occupy only 8–15% of the image height,
creating the illusion that they are exploring a world of gigantic themed elements.

The selected theme should dominate the composition. Fill the frame with enormous versions of the themed objects,
extending beyond every edge to form immersive walls, tunnels, canyons, or corridors. Avoid distant scenery,
buildings, or wide landscapes. Let the oversized environment become both the foreground and background, with only
soft light filtering between the massive forms.

Photograph the scene from within the environment using a medium telephoto perspective. Place large foreground
elements close to the camera to create soft blur, layered depth, and natural peek-through framing.

Dress the subject in sophisticated, unbranded clothing and accessories that complement the theme. Pose them
naturally while exploring—walking, peeking, touching, leaning, or quietly admiring the surroundings. Use authentic
expressions and beautiful natural light with realistic textures, shallow depth of field, and cinematic contrast. The
finished image should resemble a luxury editorial where the immersive environment is the unmistakable focal point.
```

## Usage Notes

Use these with a clear selfie or portrait reference. The example images use a fictional subject where the original prompt expects an uploaded photo.

The example image shown for this file uses made-up input details so the prompt can be previewed without a real upload.

The example image uses a giant strawberries and whipped cream theme.
