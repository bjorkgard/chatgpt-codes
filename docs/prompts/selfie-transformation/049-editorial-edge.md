# Editorial Edge

![Editorial Edge example](../../../examples/prompts/selfie-transformation/049-selfie-transformation-editorial-edge.png)

## Prompt

```text
Upload a selfie or headshot. Use it as inspiration for the subject's recognizable identity,
facial features, hairstyle, and overall presence while freely reimagining the wardrobe,
pose, lighting, composition, background, and artistic interpretation. Prioritize creating a
striking editorial illustration over faithfully recreating the original image.

Place the subject in a minimalist studio with an off-white or light gray seamless
backdrop. Pose them confidently with a relaxed yet powerful stance that conveys

modern sophistication. Dress them in oversized monochromatic tailoring with structured
layers, wide-leg trousers, sleek footwear, minimal accessories, and optional narrow
sunglasses. Keep the expression calm, confident, and editorial.

Light the scene with soft directional studio lighting that creates sculptural shadows and
depth. Maintain a restrained monochrome palette, introducing a single bold accent
color—such as coral, electric blue, lime, or hot pink—through the illustrated elements.

Surround the portrait with expressive hand-drawn marker doodles including lightning
bolts, arrows, spirals, stars, scribbles, motion lines, geometric shapes, underlines, and
abstract accents. Add a few large motivational words and short hand-lettered phrases
that wrap naturally around the subject. Preserve realistic skin texture and photographic
lighting while letting the bold doodles become a defining visual feature. The final image
should feel fearless, artistic, energetic, and worthy of a contemporary fashion magazine
cover.
```

## Usage Notes

Use these with a clear selfie or portrait reference. The example images use a fictional subject where the original prompt expects an uploaded photo.

The example image shown for this file uses made-up input details so the prompt can be previewed without a real upload.
