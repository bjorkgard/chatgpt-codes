# Little Helper

![Little Helper example](../../../examples/prompts/selfie-transformation/046-selfie-transformation-little-helper.png)

## Prompt

```text
Create a premium lifestyle portrait using the uploaded **selfie** as the reference. Preserve the subject's recognizable
identity, including their facial features, face shape, eye color, smile, skin tone, hairstyle, hair color, and overall
appearance. Dress them in a stylish outfit that complements a soft feminine pastel stationery aesthetic.

Place the subject inside a beautifully organized stationery studio with a clean, minimalist boutique feel. Include
planners, journals, notebooks, pens, markers, washi tape, stickers, scissors, paper clips, sticky notes, ribbon, and
decorative storage arranged with generous spacing and plenty of negative space.

Surround the subject with **5–7** collectible-style chibi versions of themselves in a cohesive kawaii illustration style
with oversized heads, expressive eyes, rounded proportions, and playful personalities. Show each chibi doing a
different stationery-themed activity, such as decorating a planner, organizing supplies, peeking from a pencil cup,
holding oversized scissors, or creating harmless mischief.

Scatter hand-drawn doodles like hearts, stars, bows, sparkles, arrows, paper clips, and speech bubbles throughout
the composition. Include one handwritten-style phrase such as **"Tiny Me, Big Ideas."** Use soft natural daylight and
a pastel palette of blush, cream, butter yellow, baby blue, sage, lavender, warm white, and light wood tones.
Compose a vertical **4:5** portrait with the subject filling most of the frame, leaving generous negative space for a
polished stationery-cover aesthetic.
```

## Usage Notes

Use these with a clear selfie or portrait reference. The example images use a fictional subject where the original prompt expects an uploaded photo.

The example image shown for this file uses made-up input details so the prompt can be previewed without a real upload.
