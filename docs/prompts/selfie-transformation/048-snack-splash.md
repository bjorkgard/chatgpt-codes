# Snack Splash

![Snack Splash example](../../../examples/prompts/selfie-transformation/048-selfie-transformation-snack-splash.png)

## Prompt

```text
Create an ultra-realistic lifestyle portrait using the uploaded headshot or Selfie. Preserve
the subject’s recognizable facial features, face shape, skin tone, hairstyle, smile, and
overall appearance. Dress them in a stylish outfit that complements the setting instead
of copying the reference photo.

Place the subject in a vibrant food-inspired location such as a café, bakery, amusement
park, farmers market, beach boardwalk, picnic, or colorful festival. Have them happily
holding an oversized snack in one hand and a large colorful drink in the other, both
dramatically extended toward the camera using forced perspective so they appear
larger than life.

Capture the drink at the exact moment it erupts into a spectacular frozen splash with
realistic liquid arcs, droplets, and motion suspended like high-speed photography. The
snack should appear fresh, oversized, detailed, and equally eye-catching.

Give the subject a joyful, playful expression as though proudly showing off their favorite
treats. Use bright natural light, vibrant colors, crisp detail, a slightly wide-angle
perspective, shallow depth of field, and premium editorial photography. The final image
should feel energetic, whimsical, polished, and instantly shareable, with the oversized
food and dramatic splash serving as the unforgettable focal point.
```

## Usage Notes

Use these with a clear selfie or portrait reference. The example images use a fictional subject where the original prompt expects an uploaded photo.

The example image shown for this file uses made-up input details so the prompt can be previewed without a real upload.
