# Legendary Hero

![Legendary Hero example](../../../examples/prompts/fortune-teller/096-fortune-teller-legendary-hero.png)

## Prompt

```text
Which Famous Hero or Heroine Are You?

Creator Inputs Required

    ●      Reference Selfie: Upload one clear, high-resolution selfie.
    ●      Gender: Enter the subject’s gender.

Analyze the subject’s facial features, expression, posture, styling, presence, warmth, confidence, strength, and
overall visual energy to determine which classic hero or heroine they most closely resemble. Use the provided gender
when selecting the character.

Choose one hero or heroine from literature, mythology, folklore, fairy tales, historical legends, or other public-domain
stories. Select an authentic, flattering match based on the subject’s overall essence rather than hair color or clothing
alone. Use only public-domain interpretations and avoid modern protected character designs.

Preserve the subject’s recognizable identity. Do not transform them into the character.

Create an elegant magazine-style personality profile with sophisticated typography, generous negative space, refined
decorative details, and a cohesive palette inspired by the character’s world.

Include:

Which Famous Hero or Heroine Are You?

You Are: [Character Name]

Write a warm editorial profile describing their shared traits, strengths, leadership style, approach to challenges,
emotional qualities, and inspiring characteristics.

Add Why You Were Chosen with 4–6 concise observations.

Incorporate tasteful symbolic imagery and subtle ornamental accents.

Finish with a verified public-domain quote or an original inspirational quote.

Create a luxurious, frame-worthy keepsake celebrating the subject’s unique heroic spirit.

If Your Life Were A Movie...
```

## Usage Notes

Fill in the requested personal inputs before generating. For prompts requiring a selfie, use a clear reference image and keep the identity-preservation instructions.

The example image shown for this file uses made-up input details so the prompt can be previewed without a real upload.
