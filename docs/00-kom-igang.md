# Kom igång

## Vad materialet gör

Källmaterialet visar hur korta kodord kan fungera som visuella instruktioner. Ett kodord kan styra kameravinkel, presentation, diagramtyp, material, illustration, värld, ljus eller pedagogiskt format.

## Tre användningsnivåer

- Enkel: skriv bara kodordet efter att du laddat upp en bild.
- Styrd: kombinera kodordet med ett konkret mål och format.
- Avancerad: kombinera två till fyra kompatibla kodord och lägg till begränsningar.

## Bra kombinationer

- Produktannons: `/packshot + /rimlight + /storyad`
- Teknisk förklaring: `/cutaway + /labels + /blueprint`
- Pedagogik: `/whiteboard + /keytakeaways + /diagram`
- Stiltest: `/watercolor + /goldenhour`
- Jämförelse: `/beforeafter + /featurematrix`

## Risker att undvika

- För många kodord på en gång ger ofta röriga bilder.
- Kodord som drar åt olika håll kan konkurrera, till exempel `/minimal` och `/crunch explosion`.
- Om identitet, produktform eller färger måste bevaras behöver du säga det uttryckligen.
- Text i genererade bilder kan bli fel; be hellre om korta etiketter och kontrollera alltid resultatet.
