# Prompt Patterns

## 1. Image to Ad

`/packshot Turn [product] into a clean studio image for [channel]. Emphasize [benefit], preserve [brand traits], use [format].`

## 2. Image to Technical Explanation

`/cutaway Show the inside of [object]. Label [important parts], use short labels, arrows, and a clean technical style.`

## 3. Idea to Educational Overview

`/infographic Explain [topic] for [audience]. Divide it into [number] blocks with headings, simple icons, and a clear reading order.`

## 4. Product to Campaign Series

`/socialcarousel Create [number] connected images for [campaign]. Each image should have a clear message and the same visual system.`

## 5. Scene to Alternative World

`/futurecity Place [subject] in a believable future environment. Preserve the subject's form, but update surroundings, lighting, and details.`

## 6. Comparison and Decision

`/featurematrix Compare [options] across [criteria]. Make the recommendation visually easy to see without much text.`

## 7. Everyday ChatGPT Image Recipe

`[subject] in [setting or action], [two to four code words], [colors and mood], for [use case], [aspect ratio], [things to avoid].`

## 8. Social Post With Text Space

`/ruleofthirds + /negativespace + /coverstory Create [subject] for a vertical social post. Place the subject on [side], leave clean open space on [side], use [lighting], no generated headline text.`

## 9. Cleaner Text in Images

`/textmedium + /textcontainer Create [visual]. Put only "[short exact text]" inside [sign, label, banner, card, or plaque]. Keep spelling readable and avoid extra words.`

## 10. Prompt Cleanup Helper

`Help turn this rough idea into one polished image prompt. Treat slash codes as visual shorthand, resolve conflicts based on the use case, preserve [must-keep details], and avoid [unwanted details].`
