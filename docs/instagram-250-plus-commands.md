# Instagram 250+ Commands Additions

For code words extracted from the supplied Instagram image. These are listed as exact slash forms from the image when they were not already present in the existing catalog.

## When This Group Fits

Use it when you want quick style, world, material, game, branding, or UI shortcuts from the poster source while still combining them with a subject, purpose, format, and constraints.

## Examples

- `/mangacover`: Create a dramatic manga-cover treatment for a character concept.
- `/quantumbench + /nanotech`: Turn a product idea into a futuristic lab-bench visualization.
- `/waxseal + /emblem`: Create a formal heritage-brand mark for a packaging concept.

```text
/mangacover + /inkdrawing
Create a dramatic manga-cover image for an original cyber detective character. Use clean black ink lines, bold action framing, expressive eyes, speed marks, and high contrast. Leave room for a short title at the top, but do not generate unreadable filler text.
```

```text
/ancientegypt + /goldluxury
Transform a modern perfume bottle into a premium ancient-Egypt-inspired campaign visual. Use polished gold accents, lapis-blue details, carved stone, warm torchlight, and a symmetrical temple backdrop. Keep the bottle shape clear and avoid extra brand text.
```

```text
/crystal + /pearlescent
Turn a simple wireless speaker into a faceted crystal object with pearlescent color shifts. Use clean studio lighting, soft reflections, sharp edges, and a premium product-photo composition. Preserve the speaker silhouette and avoid making it look fragile or broken.
```

```text
/bossfight + /retroarcade
Create a retro arcade boss-fight scene where a giant coffee machine is the final boss. Use pixel-game energy, dramatic UI-style health bars, glowing attacks made of steam, and a dark arcade color palette. Keep the scene playful and readable.
```

```text
/waxseal + /crest
Create a heritage-brand mark for an imaginary stationery company. Combine a wax-seal look with a formal crest, simple initials, paper texture, and restrained gold highlights. Make it elegant, centered, and usable as a packaging stamp.
```

```text
/appui + /darkmode + /neonui
Design a dark-mode mobile dashboard for a habit-tracking app. Use subtle neon highlights, clean cards, readable charts, and compact controls. Keep the interface practical, with clear hierarchy and no decorative filler text.
```
