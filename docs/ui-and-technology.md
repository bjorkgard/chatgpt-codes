# UI and Technology

For app screens, dashboards, interface styles, technical rooms, and science-tech concepts.

## When This Group Fits

Use it when the image should show software, data, computing, or advanced technology as the main subject.

## Examples

- `/appui + /darkmode + /neonui`: Design a dark-mode mobile dashboard for a habit-tracking app. Use subtle neon highlights, clean cards, readable charts, and compact controls. Keep the interface practical, with clear hierarchy and no decorative filler text.
- `/quantumbench + /nanotech`: Turn a product idea into a futuristic lab-bench visualization with quantum equipment, tiny-scale detail, and clean scientific lighting.
- `/dashboard + /cpu`: Create a system-monitor dashboard for CPU performance. Use compact charts, readable numbers, and a practical dark interface.
